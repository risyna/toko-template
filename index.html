Ubah Informasi Akun

Syarat & Ketentuan

Selamat datang di Jvro. Dengan melakukan transaksi di platform kami, Anda menyetujui ketentuan berikut:

1. Hak Kepemilikan File

Template web interaktif berformat HTML yang Anda beli bersifat permanen. Sekali dibeli dan diunduh, file tersebut 100% menjadi hak milik Anda.

2. Larangan Menjual Ulang (Resell)

Pengguna DILARANG KERAS memperjualbelikan ulang (resell) file Source Code atau memodifikasi file template Jvro untuk tujuan komersil tanpa izin tertulis dari pihak Jvro Finance.

3. Kebijakan Pengiriman & Pengembalian

File HTML dikirim secara instan ke kontak (WhatsApp/Email) Anda segera setelah Midtrans mengkonfirmasi pembayaran. Mengingat sifat produk adalah barang digital, kami tidak melayani pengembalian dana (Refund) setelah file terkirim secara sistem.

Kebijakan Privasi

Jvro sangat menghargai dan melindungi kerahasiaan data pribadi Anda. Berikut adalah cara kami menangani data Anda:

1. Keamanan Data Personal

Foto, musik, teks, dan pesan cinta yang Anda masukkan ke dalam form generator tidak pernah kami simpan secara permanen di database publik. Sistem kami langsung mengubahnya menjadi kode teks (Base64) yang menyatu dengan file HTML pesanan Anda.

2. Data Kontak Pelanggan

Nomor WhatsApp dan Alamat Email yang Anda berikan semata-mata hanya digunakan oleh bot sistem kami untuk mengirimkan file HTML pesanan Anda secara otomatis.

3. Keamanan Transaksi

Seluruh proses pembayaran diamankan dan ditangani langsung secara profesional oleh pihak Midtrans. Jvro tidak mengumpulkan atau menyimpan rincian informasi kartu atau dompet digital Anda.
